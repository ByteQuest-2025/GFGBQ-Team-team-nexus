# GFGBQ-Team-team-nexus
# Problem Statement
Phone call frauds are increasing rapidly, with scammers impersonating banks,
government officials, and service providers. Existing fraud detection systems
are mostly reactive and identify scams after the call has ended. There is a
need for an AI-based solution that can detect fraudulent calls in real time
and alert users during the ongoing conversation.

# Project Overview
This project presents an AI-powered real-time call fraud detection system
designed to identify and prevent voice-based scams during live phone calls.
The system analyzes call audio using speech-to-text conversion, applies NLP
techniques to extract fraud-related patterns, and uses a machine learning
model to classify calls as safe, suspicious, or fraudulent. Real-time alerts
are generated to warn users before financial damage occurs.

---

# Features
- Real-time call audio analysis
- Speech-to-text based fraud detection
- NLP-driven scam keyword detection
- Machine learning-based fraud classification
- Live fraud risk score and alerts
